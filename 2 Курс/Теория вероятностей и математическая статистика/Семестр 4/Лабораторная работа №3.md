3. Вычисление генеральных средних X и Y
	Формулы вычисления генеральных средних: $$\bar{X} = \frac{\sum{(x_i\cdot n_{i})}}{N};\bar{Y} = \frac{\sum{(y_j\cdot n_{j})}}{N};\overline{XY} = \frac{\sum{(x_i\cdot y_j\cdot n_{j})}}{N};
	\overline{X^2} = \frac{\sum{(x_i^2\cdot n_{i})}}{N};
	\overline{Y^2} = \frac{\sum{(y_j^2\cdot n_{j})}}{N}$$
	$\bar{X}=\frac{5\cdot4+10\cdot43+15\cdot72+20\cdot52+25\cdot32+30\cdot17+35\cdot10+40\cdot7+45\cdot3+50\cdot4​}{244}\approx19.9$
	$\bar{Y}=\frac{1\cdot17+2\cdot91+3\cdot64+4\cdot41+5\cdot19+6\cdot7+7\cdot2+8\cdot1+9\cdot1+10\cdot1}{244}\approx3$
	$\overline{XY}=\frac{5\cdot1\cdot3+5\cdot5\cdot1+10\cdot1\cdot9+\dots+50\cdot9\cdot1+50\cdot10\cdot1}{244}\approx67.9$
	$\overline{X^2}=\frac{5^2\cdot4+10^2\cdot43+\dots+45^2\cdot3+45^2\cdot4}{244}\approx476.3$
	
4. Составление уравнения регрессии
	- Y на X: 
		Уравнение регрессии Y на X: $$\hat{y}=ax+b$$
		$cov(X,Y)=\frac{\sum{(x_i\cdot y_i\cdot n_{ij})}}{N}-\bar{X}\cdot\bar{Y}=\frac{(5\cdot1\cdot3+5\cdot5\cdot1+\dots+50\cdot9\cdot1+50\cdot10\cdot1)}{244}-19.9\cdot3\approx 8.2$
		$S_x^2=\frac{\sum{(x_i^2\cdot n_i)}}{N}-\bar{X}^2=\frac{5^2\cdot4+10^2\cdot43+\dots+45^2\cdot3+50^2\cdot4}{244}-19.9^2\approx80.3$
		$a=\frac{cov(X,Y)}{S_x^2}=\frac{8.2}{80.3}\approx0.1$
		$b=\bar{Y}-a\bar{X}=3-0.1\cdot19.9=1$
		$\hat{y}=0.1x+1$
		![[Pasted image 20250603013233.png]]
	- X на Y: 
		Уравнение регрессии X на Y: $$\hat{x}=cy+d$$
		$cov(Y,X)=cov(X,Y)\approx 8.2$
		$S_y^2=\frac{\sum{(y_j^2\cdot n_j)}}{N}-\bar{Y}^2=\frac{1^2\cdot17+2^2\cdot91+\dots+8^2\cdot1+9^2\cdot1}{244}-9^2\approx2$
		$c=\frac{cov(X,Y)}{S_y^2}=\frac{8.2}{2}=4.1$
		$d=\bar{X}-c\bar{Y}=19.9-4.1\cdot3=7.6$
		$\hat{x}=4.1y+7.6$
		![[Pasted image 20250603013248.png]]
5. Прогноз ожидаемого Y по выбранному X
	Пусть $X=12$, тогда $\hat{Y}=0.1\cdot12+1=2.2$
6. Оценка тесноты связи между X и Y
	Коэффициент корреляции: $$r=\frac{cov(X,Y)}{S_x\cdot S_y}=\frac{8.2}{\sqrt{80.3}\cdot \sqrt{2}}\approx0.6$$
7. Оценка существенности выборочного коэффициента корреляции
	Выдвинем гипотезу $H_0$ - корреляция отсутствует и альтернативную ей $H_1$ - корреляция есть
	Воспользуемся критерием Стьюдента: $$t=r\sqrt{\frac{N-2}{1-r^2}}=0.6\cdot \sqrt{\frac{244-2}{1-0.6^2}}\approx11.7$$
	Критическое значение $t_{крит}=t_{\alpha=0.05;df=242}\approx1.97$
	Так как $t>t_{крит}$, то можно сделать вывод, что присутствует значимая корреляция
8. Поиск 95%-ных доверительных интервалов для среднего значения и коэффициентов уравнения регрессии
	Доверительный интервал для генерального среднего:$$\bar{Y}\pm t_{\alpha/2}\cdot \frac{S_y}{\sqrt{N}}=3\pm1.97\cdot\frac{\sqrt{2}}{\sqrt{244}}\approx3\pm0.18$$
	Получается $\bar{Y}\in [2.82, 3.18]$
	
	Доверительный интервал для a: $$a\pm t_{\alpha/2}\cdot SE(a),\ где\ SE(a)=\frac{S_{y/x}}{S_x\sqrt{N-1}}$$
	$S_{y/x}=\frac{\sum(y_i-\hat{y}_i)^2}{N-2}=S_y\sqrt{1-r^2}\cdot\sqrt{\frac{N-1}{N-2}}=\sqrt{2}\cdot\sqrt{1-0.6^2}\cdot\sqrt{\frac{244-1}{244-2}}\approx1.13$
	$S_x=\sqrt{80.3}\approx8.96$
	$SE(a)=\frac{1.13}{8.96\cdot\sqrt{243}}\approx0.01$
	$t_{\alpha/2}\cdot SE(a)=1.97\cdot0.01\approx0.02$
	Получается $a\in [0.08, 0.12]$
	
	Доверительный интервал для b: $$b\pm t_{\alpha/2}\cdot SE(b),\ где\ SE(b)=S_{y/x}\cdot\sqrt{\frac{1}{N}+\frac{\bar{X}^2}{(N-1)S_x^2}}$$
	$SE(b)=1.13\cdot\sqrt{\frac{1}{244}+\frac{19.9^2}{243\cdot80.3}}\approx0.18$
	$t_{\alpha/2}\cdot SE(b)=1.97\cdot0.18\approx0.35$
	Получается $b\in [0.65, 1.35]$
9. Определение вида корреляционной связи X и Y. Определение параметров криволинейной регрессии
	Судя по графику регрессии можно сделать вывод, что корреляционная связь между X и Y может быть представлена как коренная функция с формулой $\hat{y}=a\cdot \sqrt{x}+b$ или $\hat{y}=a\cdot z+b,\ где\ z=\sqrt{x}$
	Для определения параметров криволинейной регрессии был использован метод наименьших квадратов:  $$
     \begin{cases}     a \sum z_i + b n = \sum y_i \\     a \sum z_i^2 + b \sum z_i = \sum z_i y_i     \end{cases}     \Rightarrow     \begin{cases}	 a = \frac{n \sum z_i y_i - \sum z_i \sum y_i}{n \sum z_i^2 - (\sum z_i)^2}\\	 b = \frac{\sum y_i - a \sum z_i}{n}	 \end{cases}	 \Rightarrow
	 \begin{cases}	 a = \frac{244\cdot3401.3-50.2\cdot55}{244\cdot 275-50.2^2}\approx12.8\\	 b = \frac{55-a\cdot50.2}{244}\approx-2.4	 \end{cases}$$
	По найденным коэффициентам выпишем уравнение криволинейной регрессии: $$\hat{y}=12.8\sqrt{x}-2.4$$
10.  Оценка тесноты связи X и Y через коэффициент детерминации
	Формула коэффициента детерминации:$$R^2=\frac{\sum(\hat{y}_i-\bar{y})^2}{\sum(y_i-\bar{y})^2}=\frac{4178.1}{24585}\approx0.17$$
11. Оценка значимости коэффициента детерминации
	Выдвинем гипотезу $H_0: R^2=0$ - детерминация не значима $H_1: R^2>0$ - модель значима$$F=\frac{R^2(N-2)}{1-R^2}=\frac{0.17(244-2)}{1-0.17}=49.6$$
	$F_{крит}=F_{0,05;1;242}\approx3.88$
	Так как $F>F_{крит}$, то $H_0$ отвергается, а значит криволинейная модель значима.
